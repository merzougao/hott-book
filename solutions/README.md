# Written Solutions

`Hott_problems.tex` is the editable source for the written solutions and notes.
`Hott_problems.pdf` is generated from that source for convenient reading.

The manuscript is a work in progress. It intentionally retains explicit
`TODO` markers, proof sketches, and incomplete exercises.

From the repository root, regenerate the PDF with:

```sh
make pdf
```

Do not edit the PDF independently of the LaTeX source.
